# Aether

A minimal apparel landing page exploring a monochrome layout, typography, navigation styling, and a featured product section.

## Stack

HTML · CSS

## Run locally

Clone the repository and open `index.html` in a browser. No build tools or package installation are needed.

## Repository guide

- `index.html` — page markup and inline CSS.
- `blanktee.jpg` — included image asset.

## Current status

This is an early static UI prototype. Navigation links are placeholders; checkout and backend functionality are not implemented. The featured image currently references `aether-shirt.jpg`, which is not included in the repository, so that image will not display until the reference or asset is updated.
